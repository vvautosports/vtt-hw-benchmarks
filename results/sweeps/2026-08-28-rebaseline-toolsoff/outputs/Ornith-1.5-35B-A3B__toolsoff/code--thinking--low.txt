```python
def parse_ranges(s: str) -> list[int]:
    """Parse a comma-separated list of integers and ranges into a flat list.

    Whitespace around numbers and commas is ignored. A reversed range such as
    ``'9-7'`` raises ``ValueError``. Empty or whitespace-only input yields ``[]``.

    >>> parse_ranges('1-3,5,7-9')
    [1, 2, 3, 5, 7, 8, 9]
    >>> parse_ranges('1 - 3, 5 ,7-9')
    [1, 2, 3, 5, 7, 8, 9]
    >>> parse_ranges('10')
    [10]
    >>> parse_ranges('3-3')
    [3]
    >>> parse_ranges('')
    []
    >>> parse_ranges('     ')
    []
    >>> parse_ranges('9-7')
    Traceback (most recent call last):
        ...
    ValueError: reversed range '9-7'
    """
    result: list[int] = []
    for chunk in s.split(','):
        chunk = chunk.strip()
        if not chunk:
            continue
        if '-' in chunk:
            low_str, high_str = chunk.split('-', 1)
            low = int(low_str.strip())
            high = int(high_str.strip())
            if high < low:
                raise ValueError(f"reversed range '{low}-{high}'")
            result.extend(range(low, high + 1))
        else:
            result.append(int(chunk))
    return result
```

### How it works

- **Splitting:** `s.split(',')` breaks the input into comma-separated tokens.
- **Whitespace handling:** `chunk.strip()` trims surrounding whitespace. Each bound of a range is also stripped, so internal spacing like `'1 - 3'` is tolerated.
- **Empty input:** An empty string `''.split(',')` gives `['']`, and whitespace-only input gives `['     ']`; after stripping both become `''`, which the `if not chunk: continue` guard skips, yielding `[]`.
- **Ranges:** `'9-7'` is split on the first `'-'` into `'9'` and `'7'`; since `high < low`, a `ValueError` is raised. Single-element ranges like `'3-3'` correctly produce `[3]` via `range(3, 4)`.
- **Single numbers:** Tokens without a `'-'` are converted directly with `int()`.
