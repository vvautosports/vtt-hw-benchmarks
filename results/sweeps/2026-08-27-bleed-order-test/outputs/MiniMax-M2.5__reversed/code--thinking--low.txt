Here is a small, self‑contained implementation that follows the specification.  
It splits the input on commas, trims whitespace, expands each range, and raises `ValueError` if a range is given in reverse order.

```python
def parse_ranges(s: str) -> list[int]:
    """
    Convert a compact range description into an explicit list of integers.

    The description may contain single numbers, ranges, and optional whitespace.
    Whitespace around commas and numbers is ignored.  An empty or whitespace‑only
    string yields an empty list.  A reversed range (e.g. "9‑7") raises ValueError.

    Examples
    --------
    >>> parse_ranges('1-3,5,7-9')
    [1, 2, 3, 5, 7, 8, 9]

    >>> parse_ranges(' 1-3 , 5 , 7-9 ')
    [1, 2, 3, 5, 7, 8, 9]

    >>> parse_ranges('')
    []

    >>> parse_ranges('   ')
    []

    >>> parse_ranges('9-7')
    Traceback (most recent call last):
        ...
    ValueError: Invalid range: 9-7

    >>> parse_ranges('2-4,8,10-12')
    [2, 3, 4, 8, 10, 11, 12]

    >>> parse_ranges('1, 2, 3-5')
    [1, 2, 3, 4, 5]
    """
    # Empty or pure‑whitespace input -> empty list
    if not s or s.strip() == '':
        return []

    result: list[int] = []
    for part in s.split(','):
        part = part.strip()
        if not part:                     # skip empty fragments caused by stray commas
            continue

        if '-' in part:                  # a range "a-b"
            left, right = part.split('-', 1)   # split only on the first '-'
            a = int(left)
            b = int(right)
            if b < a:
                raise ValueError(f'Invalid range: {a}-{b}')
            result.extend(range(a, b + 1))
        else:                            # a single number
            result.append(int(part))

    return result
```

**Explanation of key points**

* `s.split(',')` correctly handles the commas, and `strip()` removes surrounding whitespace.
* For a range like `"a‑b"` we expand the inclusive sequence with `range(a, b+1)`. If `b < a` we raise `ValueError`.
* Single numbers are turned into integers and appended directly.
* An empty or whitespace‑only input yields an empty list as required.
* The doctests demonstrate all the requested behaviours (basic ranges, whitespace handling, reversed ranges, empty input, and a few extra cases).
