=== CONTENT ===
- **Mechanism:** A cheap draft proposes several tokens that the target model verifies in one batched forward pass; accepted tokens come at large-model quality and near-draft cost, and a rejection simply truncates the proposal so generation resumes from the last accepted position — making outputs distributionally identical to standard decoding. Drafts can be a separate small model, an n-gram lookup over prompt and generation history, or (in newer designs) a multi-token-prediction (MTP) head trained jointly with the target that predicts a short window of future tokens from the same hidden state.
- **Workload dependence:** Code and structured text repeat long spans, so n-gram drafting achieves high acceptance rates almost for free; open-ended prose accepts fewer speculative tokens, and a poorly matched draft model can make generation slower than running the target alone, since every rejected batch wastes a full verification pass.
- **MTP heads sit in between:** they add a small amount of memory and compute per step, but their acceptance rates tend to be stable across domains because the head sees exactly the context the target sees.
- **MoE targets raise the bar:** expert routing means only a fraction of total parameters are active per token (which is how models with tens of billions of parameters decode quickly on integrated GPUs with unified memory), but speculative verification batches positions that may route to different experts, pulling more expert weights through memory per step; on bandwidth-bound hardware this erodes the batching advantage that makes speculation profitable, so the break-even acceptance rate is higher for MoE than for dense targets.
- **Serving interacts with all of it:** slot-based servers split the KV-cache budget across concurrent sequences — more slots raise aggregate throughput while lowering per-stream speed — and speculation competes with extra slots for the same compute headroom, so speculative mode, slot count, and sampling settings must be tuned as one joint configuration and judged by end-to-end tokens per second on representative tasks rather than microbenchmarks.

**TL;DR:** Speculative decoding preserves target-model output quality while cutting cost, but whether it actually pays off hinges on acceptance rates that shift with workload, draft type, MoE routing, and server slot allocation — making it a jointly-tuned configuration to be measured end-to-end, not a free speedup.
