```python
def parse_ranges(s: str) -> list[int]:
    """
    Parse a comma-separated string of numbers and ranges into a flat list of integers.
    
    >>> parse_ranges('1-3,5,7-9')
    [1, 2, 3, 5, 7, 8, 9]
    >>> parse_ranges(' 1 - 3 , 5 ')
    [1, 2, 3, 5]
    >>> parse_ranges('9-7')
    Traceback (most recent call last):
        ...
    ValueError
    >>> parse_ranges('')
    []
    >>> parse_ranges('   ')
    []
    """
    s = s.strip()
    if not s:
        return []

    result = []
    for part in s.split(','):
        part = part.strip()
        if not part:
            continue
            
        if '-' in part:
            start_str, end_str = part.split('-', 1)
            start = int(start_str.strip())
            end = int(end_str.strip())
            
            if start > end:
                raise ValueError("Reversed range is not allowed")
                
            result.extend(range(start, end + 1))
        else:
            result.append(int(part))
            
    return result
```

### Key Features:
- **Whitespace handling**: Strips the entire string first, then strips each comma-separated part and individual numbers before parsing.
- **Range expansion**: Uses `range(start, end + 1)` to correctly include both boundaries.
- **Reversed range check**: Explicitly validates `start <= end` and raises `ValueError` otherwise.
- **Empty/whitespace input**: Early return for `""` or whitespace-only strings.
- **Doctests**: Covers basic parsing, whitespace tolerance, reversed range error, empty string, and whitespace-only string (5 examples total).
